# 30-60-90 Day Plan

## First 30 Days

- Learn commerce domain objects and the existing API architecture.
- Understand identity provider, API gateway, deployment, and observability standards.
- Run existing partner POCs locally.
- Fix small docs/test gaps.
- Ship one low-risk endpoint or MCP tool improvement.

## Days 31-60

- Own a vertical slice such as quote, order status, or partner onboarding.
- Add contract tests and auth checks.
- Improve webhook verification, idempotency, and partner retry handling.
- Document repeatable POC setup steps.

## Days 61-90

- Lead hardening for one partner integration.
- Define a reusable MCP tool template.
- Add eval coverage for agentic workflows.
- Create a production-readiness checklist for future partner launches.
